# 🛒 AI-Powered Retail Intelligence & Sales Prediction Platform

## 📌 Overview

This project is an end-to-end Data Science and Machine Learning application that predicts retail sales using XGBoost Regression. It includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training, prediction, visualization, and downloadable PDF reports through a Streamlit web application.

---

## 🚀 Features

- Sales Prediction using XGBoost
- Interactive Streamlit Dashboard
- PDF Report Generation
- Feature Importance Analysis
- Model Performance Metrics
- Data Cleaning Pipeline
- Exploratory Data Analysis (EDA)
- Feature Engineering
